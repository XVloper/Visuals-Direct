Install MV Visuals (Direct Install Made By Jerry)

Two quick steps, in order, using Safari on your iPhone or iPad.

This page only works in Safari on iOS. Open this link in Safari to continue.

  1. Add the DNS profile(Step 1)

    Tap the button, choose Allow, then open Settings and tap “Profile Downloaded” to install it. Do this first.

    Download DNS profile

  2. Install MV Visuals(Step 2)

    Tap Install on the prompt that appears. The app shows up on your Home Screen while it downloads.

    Install MV Visuals
App says “Untrusted Developer”

Go to Settings › General › VPN & Device Management, tap the developer profile listed under Enterprise App, then tap Trust.

The install prompt doesn’t appear

Make sure you’re in Safari, not an in-app browser. Reload this page and tap Install again.

The app stopped opening

Check that the DNS profile is still installed in Settings › General › VPN & Device Management. If it is, delete the app and install it again.

How do I remove the DNS profile?

Open Settings › General › VPN & Device Management, tap the DNS profile, then tap Remove Profile.
